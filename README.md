# รุ่งเรือง เรื่องไร่ · สมุดบัญชีโดรนเกษตร T55

เว็บแอปบันทึกรายรับ-รายจ่ายงานรับจ้างโดรนเกษตร ประวัติลูกค้าและแปลง ประวัติสาร (IRAC/FRAC) คำแนะนำการพ่น และแผนที่งานพร้อมภาพดาวเทียม

## วิธีขึ้น GitHub Pages (ทำครั้งเดียว)

1. เข้า github.com → กด **New repository** → ตั้งชื่อ เช่น `drone-ledger` → เลือก **Public** → กด **Create repository**
2. ในหน้า repo กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง → กด **Commit changes**
3. ไปที่ **Settings → Pages** → ช่อง *Source* เลือก **Deploy from a branch** → Branch เลือก **main** และโฟลเดอร์ **/(root)** → กด **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/drone-ledger/`

## ติดตั้งเป็นแอปบนมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป**
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ครั้งแรกที่กด 📍 GPS เบราว์เซอร์จะถามสิทธิ์ตำแหน่ง ให้กด **อนุญาต**

## ข้อมูลเก็บที่ไหน (สำคัญ)

- ข้อมูลเก็บใน **เบราว์เซอร์ของเครื่องที่ใช้งาน** ไม่ได้ขึ้นไปอยู่บน GitHub (repo มีแต่ตัวโปรแกรม ไม่มีข้อมูลลูกค้า)
- มือถือกับคอมจะ **ไม่เห็นข้อมูลของกันและกันอัตโนมัติ** — ย้ายข้อมูลด้วย **ตั้งค่า → สำรองทั้งหมด (JSON)** แล้ว **กู้คืนจากไฟล์ JSON** ในอีกเครื่อง
- ถ้าล้างข้อมูลเบราว์เซอร์ / ลบแอป / เปลี่ยนเครื่อง ข้อมูลจะหาย → **สำรองไฟล์ทุกสัปดาห์** (แอปจะเตือนเมื่อครบ 7 วัน)


## เปิดใช้คลาวด์ (Firebase)

1. แก้ไฟล์ `firebase-config.js` ใน repo (กดรูปดินสอ ✏️) แล้ววางค่า firebaseConfig จาก Firebase Console แทน `null`
2. ใน Firebase › Authentication › Settings › Authorized domains เพิ่ม `pakaplonfarm.github.io`
3. ใส่กฎ (Rules) ของ Firestore ตามที่ได้รับ — กำหนดอีเมลที่มีสิทธิ์ใช้ข้อมูล
4. เปิดเว็บ → เข้าสู่ระบบด้วย Google → ข้อมูลซิงก์ทุกเครื่อง

ค่า firebaseConfig ใส่ใน repo สาธารณะได้ (ไม่ใช่รหัสลับ) ความปลอดภัยของข้อมูลมาจากการล็อกอินและกฎ Firestore
